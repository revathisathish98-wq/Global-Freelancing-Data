# Global-Freelancing-Data
Data Visualization - Dashboard

#**Project Overview**
This Freelancer Dataset Project focuses on Exploring, Cleaning, and analyzing data related to freelancers rom different countries their skills, project and client ratings. This Project aims to uncover meaningful insights that can help freelancers and client marketplace platforms make better decisions.

#**Objective Dataset Description**
The main goal of the project is to understand performance ratings with skill trends in freelance platforms by analyzing factors such as:
Freelancer ID, Name, Country, Skills, No.of projects, Duation etc.,
